# react-native-lite-text

Fast and Lightweight static text package for React Native

## Installation


```sh
npm install react-native-lite-text
```


## Usage


```js
import { LiteTextView } from "react-native-lite-text";

// ...

<LiteTextView color="tomato" />
```
